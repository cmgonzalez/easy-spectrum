# Easy Spectrum

Emulador de ZX Spectrum (16K/48K/128K/+2/+2A/+3) para Android, hecho en Flutter por EasySoft SPA.

- Core: [Clock Signal](https://github.com/TomHarte/CLK) de Thomas Harte (MIT), vía dart:ffi.
- Formatos: `.tap` `.tzx` `.csw` `.z80` `.sna` `.szx` `.dsk` y `.zip`.
- Teclado ZX en pantalla y joystick (Kempston, Sinclair, Cursor, QAOP).

```bash
git clone --recurse-submodules https://github.com/cmgonzalez/easy-spectrum.git
```

Las ROMs del Spectrum son copyright de Amstrad plc, que permite su distribución con emuladores.
